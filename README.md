# Carnet du Conseil Saint Mommolin — application publiée

Ce dépôt ne contient que l'application servie en ligne. Il est public parce qu'il
**ne contient aucune donnée** : ni nom de frère, ni effectif, ni séance, ni compte rendu.

Tout ce que le secrétaire saisit reste dans son téléphone (stockage local du navigateur).
Aucun serveur, aucune base, aucun compte : le site ne livre que du code.

Cette contrainte n'est pas cosmétique. Nommer une personne comme membre d'un ordre
catholique révèle ses convictions religieuses, donnée de l'article 9 du RGPD : rien de
tel ne doit se trouver sur une adresse publique.

Les sources, les maquettes, la recette et les documents de référence vivent dans un
dépôt privé séparé.
